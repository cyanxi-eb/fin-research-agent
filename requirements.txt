# ---- 鉴权与网络搜索（本轮新增）----
PyJWT>=2.8               # JWT 签发/校验（HS256）；签名校验不自己造轮子

# 沿用本项目「能自写就不引重依赖」的一贯取舍（同 config.py 对 akshare 的处理）。
# 登录入参用 JSON 而非 OAuth2PasswordRequestForm，故**不需要 python-multipart**。

# ---- 编排（Step 3 起启用）----
langchain-openai>=0.2    # ChatOpenAI（走 OpenAI 兼容接口，多供应商共用）
langgraph>=0.2           # retrieve→generate→cite 子图；Step 5 扩成主图（router/verify/HITL）
# Step 5 HITL（人工确认）必需：**没有它 interrupt() 无法落盘，挂起就等于丢状态**。
# 本步只用 SQLite；MySQL 后端见下面被注释的 langgraph-checkpoint-mysql。

# ---- 数据源双后端（Step 2 起启用；沿用 workflow-agent 的成熟方案）----

# ---- 检索增强（Step 4 起启用）----

# 不用 chromadb / faiss：这个量级上 ANN 只会白白引入近似召回损失，

# sentence-transformers>=3.0   # 仅 EMBEDDING_BACKEND=local 时需要（离线通道，要下权重）；api 通道不需要
# chromadb>=0.5                # 数据量上万后再换 ANN 时放开；只需替换 src/retrieve/vector.py

# ---- 评估（Step 6 起启用）----
# 检索级评测已在 Step 4 用纯标准库 + numpy 做完（scripts/eval_retrieval.py，不调模型、零依赖）；
